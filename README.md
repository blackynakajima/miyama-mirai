# 美山 未来思考 — 学校が残れば、町は続く

京都府南丹市美山町の人口動態と、美山小・中学校の10年推計をもとに、教育を軸にした中山間地の再生モデルを提言するWebサイトです。

- 運営：NPO法人 森の教育プロジェクト
- 協力：一般社団法人 わっしょい
- 形式：静的サイト（HTML・CSS・JavaScriptの1ファイル構成。ビルド不要）

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例：`miyama-mirai`、Public）。
2. このフォルダの中身をすべてアップロードする。
   - ブラウザの場合：リポジトリの「Add file → Upload files」に、フォルダの中身をまとめてドラッグ。
   - コマンドの場合：
     ```bash
     git init
     git add .
     git commit -m "初回公開"
     git branch -M main
     git remote add origin https://github.com/<ユーザー名>/miyama-mirai.git
     git push -u origin main
     ```
3. リポジトリの「Settings → Pages」を開き、「Branch」を `main`、フォルダを `/ (root)` にして保存。
4. 数分後、`https://<ユーザー名>.github.io/miyama-mirai/` で公開される。

## 公開前に書き換える箇所

### 1. 公開URL（SITE_URL）

`index.html`、`robots.txt`、`sitemap.xml` の中にある次のURLを、実際の公開URLに置き換えてください（ファイル内で一括置換）。

```
https://blackynakajima.github.io/miyama-mirai/
```

- リポジトリ名を `miyama-mirai` 以外にした場合
- 独自ドメイン（例：`https://miyama.edu-project.jp/`）で公開する場合

どちらも、末尾の `/` を付けたまま置き換えます。SNSでシェアしたときの画像（`og:image`）は、このURLが正しくないと表示されません。

### 2. Googleアナリティクスの測定ID（GA_ID）

1. [Googleアナリティクス](https://analytics.google.com/) でプロパティを作り、「ウェブ」のデータストリームを追加する（URLは公開URL）。
2. 表示される「測定ID」（`G-` で始まる）をコピーする。
3. `index.html` の次の行を書き換える。
   ```js
   window.GA_MEASUREMENT_ID = 'G-XXXXXXXXXX';
   ```
4. **データストリームの設定 →「拡張計測機能」→「ページビュー」の詳細設定で、「ブラウザの履歴イベントに基づくページの変更」をオフにする。**
   このサイトはページ切り替えのたびに自分でページビューを送っているため、オンのままだと二重に数えられます。

測定IDが `G-XXXXXXXXXX` のままのときは、アナリティクスのタグは読み込まれません。

**計測される内容**

| イベント | 内容 |
| --- | --- |
| `page_view` | 各ページ（`#why` など）の表示。ページ名は「01 構造を知る」などのタイトルで記録 |
| `simulator_change` | シミュレーターのボタン操作（`param`：h＝移住世帯数／b＝出生数、`value`：変更後の値） |

フッターに、Googleアナリティクスを使っている旨の記載があります。

### 3. 問い合わせ先

「08 参加する」ページのメールアドレス（`mori-info@edu-project.jp`）が正しいか確認してください。`index.html` 内を検索すると、まとめて見つかります。

## 独自ドメインで公開する場合（任意）

1. 「Settings → Pages → Custom domain」にドメイン（例：`miyama.edu-project.jp`）を入力して保存する。リポジトリに `CNAME` ファイルが自動で作られる。
2. ドメインのDNS設定で、サブドメインの CNAME レコードを `<ユーザー名>.github.io` に向ける。
3. 反映後、「Enforce HTTPS」にチェックを入れる。
4. 上の「1. 公開URL」をすべて新しいドメインに書き換える。

## 数値を更新するとき

市の統計が新しくなったら、次の箇所を書き換えます。すべて `index.html` の中にあります。

| 更新するデータ | 書き換える場所 |
| --- | --- |
| 学年別の児童生徒数・推計値 | スクリプト内の `eP`（小学生推計）、`jP`（中学生推計）、`mP`（移住シナリオ）、`eA` / `jA`（実績） |
| 推計の一覧表 | 「データと出典」ページの「推計の方法」の表 |
| 総人口・16〜29歳 | 「02 データ」ページの指数グラフ（`polyline` の座標）と表 |
| トップの指標 | トップページの `data-count` の値（−37%、−53%、約40人） |
| 出典 | 「データと出典」ページの参考文献リスト（`id="r1"`〜`id="r19"`） |

推計はコーホート進級法です（翌年度の n 年生＝今年度の n−1 年生、転出入なし）。計算方法の詳細は、サイトの「データと出典」ページに載せています。

### 元データで確認したい項目（2026年11月時点）

- 美山地域の総人口と16〜29歳人口（2006〜2026年）：南丹市の住民基本台帳（地域別・年齢別）
- 未就学児の年齢別人数：令和7年度第1回 南丹市総合教育会議の配布資料
- 2026年5月1日現在の学年別児童生徒数：南丹市「園児・児童・生徒の状況」令和8年版
- 1995年・2006年の児童生徒数：学校基本調査（学校別）または南丹市教育委員会の記録

確認できたら、サイトの該当箇所と「データと出典」ページの「今後確認する項目」「更新履歴」を更新してください。
